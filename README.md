# QUANTA — Ashwin Xavier Francis

Research portfolio: https://ashlyxf.github.io/

The HTML, CSS and JavaScript in this repository are the editable site source. GitHub Pages deploys on changes to these files, the assets directory or the Pages workflow.

The complete media and document bundle is included in the `v1.1.0` release as `quanta-portfolio.zip`. The deployment verifies its SHA-256, extracts it, then overlays the current repository files so text and layout edits publish directly from `main`.

To preview the complete portfolio locally, download and extract that release archive, overlay this repository's site files, and serve the directory with `python -m http.server 8000`.

TALOS includes the project report and eight recordings. The CU Boulder collection lists projects in descending date order.
